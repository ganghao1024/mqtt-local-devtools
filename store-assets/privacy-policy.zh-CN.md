# MQTT Local DevTools 隐私政策

生效日期：2026 年 8 月 21 日

## 1. 扩展用途

MQTT Local DevTools 的单一用途是在 Chrome DevTools 中监听、解析和展示当前本地或线上网页已有的 MQTT over WebSocket 连接与报文，帮助开发者进行联调和故障排查。所有数据处理均在当前浏览器本地完成。

## 2. 处理的数据

为实现上述功能，扩展可能在用户主动调试的页面中处理以下数据：

- 页面 URL、页面标题和浏览器标签页标识；
- WebSocket 连接地址和连接状态；
- MQTT Client ID、协议版本、Topic、QoS、报文类型和时间戳；
- MQTT Payload 的文本、JSON 或十六进制预览；
- 用户在扩展面板中输入的本地筛选关键字。

这些数据可能包含用户或网站提供的内容。扩展不会尝试识别用户身份，也不会将这些数据用于调试功能之外的目的。

## 3. 数据收集、使用和共享

- 扩展不会把上述数据发送给开发者或任何第三方服务器。
- 扩展不会出售、出租或共享用户数据。
- 扩展不会将数据用于广告、个性化推荐、信用评估或与核心调试功能无关的分析。
- 扩展不使用远程代码。

## 4. 数据存储与保留

MQTT 连接和报文只保存在当前页面与 DevTools 会话的浏览器内存中，扩展后台只实时转发事件，不保存报文。DevTools 未连接时，每个页面最多缓存最近 1000 个事件且不超过 8 MiB；DevTools 已连接时，页面回放窗口缩短为 200 个事件且不超过 2 MiB；DevTools 面板独立保留最多 5000 个事件且不超过 32 MiB。任一限制先达到时会自动淘汰最旧事件。关闭或刷新相关页面、重新加载扩展或关闭浏览器后，对应内存数据会被清除。

扩展仅使用浏览器本地存储保存用户选择的时间排序偏好和三栏宽度，不保存 MQTT Payload。

当用户主动点击“导出 JSON”时，浏览器会把当前筛选结果下载到用户选择的本地位置。该导出文件由用户自行管理。

## 5. 网站访问权限

扩展请求访问所有 HTTP 和 HTTPS 页面，是因为开发者可能在任意域名、localhost 或 IP 地址页面调试 MQTT，并且监听器必须在页面脚本创建 WebSocket 之前注入。该权限只用于本地检测和展示 MQTT over WebSocket 数据。

## 6. 数据安全

扩展通过将数据处理限制在本地浏览器会话中来降低数据泄露风险。用户仍应避免在不可信环境中导出包含敏感 Payload 的 JSON 文件。

## 7. 政策变更

如果扩展的数据处理方式发生实质变化，本政策会在新版本发布前更新，并修改生效日期。

## 8. 联系方式

如有隐私或数据处理问题，请通过项目的 [GitHub Issues](https://github.com/ganghao1024/mqtt-local-devtools/issues) 联系开发者。
